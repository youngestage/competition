# NASA Crater Detection Landing Page

A modern, responsive landing page for the NASA Crater Detection Marathon Match hosted by Topcoder.

## Overview

This single-page application showcases the NASA Crater Detection Challenge, blending NASA's space theme with Topcoder's clean, modern design style. Built with React and Tailwind CSS for a futuristic, science-focused experience.

## Features

- **Responsive Design**: Optimized for desktop (1734px) and mobile (393px) viewports
- **Modern UI**: Minimal, futuristic design with space-themed elements
- **Smooth Animations**: Scroll animations and hover states throughout
- **Accessibility**: Semantic HTML structure and proper ARIA labels
- **Brand Integration**: Seamless blend of Topcoder and NASA branding

## Tech Stack

- React 18.2.0
- Tailwind CSS 3.3.6
- Material Design Icons
- Custom CSS animations

## Color Palette

- Deep Space Navy: `#0B0E2C`

- Topcoder Blue: `#007AFF`

## Typography

- **Headers**: Figtree font family
- **Body**: Nunito Sans font family

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

The application will run on `http://localhost:3000`

## Sections

1. **Hero Section** - Eye-catching introduction with prize announcement
2. **Overview** - Challenge importance and goals
3. **Technical Details** - In-depth technical requirements and challenges
4. **Prize Distribution** - $50,000 prize breakdown
5. **How to Participate** - 4-step participation guide
6. **Resources** - Topcoder and NASA learning materials
7. **Leaderboard** - Top 6 winners display (populated after challenge)
8. **Footer** - Branding and social links

## Customization

All content placeholders can be updated in `src/App.js`. Images and logos should be placed in the `public` folder and referenced accordingly.
